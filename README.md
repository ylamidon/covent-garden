# Plan Covent Garden

Carte interactive pour une visite guidée à pied de Covent Garden (Londres), avec 12 lieux répartis en 5 étapes.

## Voir la carte

[ylamidon.github.io/covent-garden](https://ylamidon.github.io/covent-garden/)

## Étapes

| # | Zone | Couleur |
|---|------|---------|
| 1 | Seven Dials / Neal Street | Rouge |
| 2 | Mercer / Floral Street | Orange |
| 3 | Covent Garden Piazza | Vert |
| 4 | King / Southampton / Drury Lane | Bleu |
| 5 | Trafalgar Square | Violet |

## Stack

- HTML/CSS/JS vanilla
- [Leaflet.js](https://leafletjs.com/) + OpenStreetMap
- Hébergé sur GitHub Pages
